# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-03-10

### Added

- FastAPI server mode with `/v1/*` API surface and bearer auth.
- TypeScript HTTP SDK (`sdk/typescript`) with typed client and error mapping.
- Benchmark suite (`benchmarks/run.py`) with JSON + markdown output.
- Server/docs/examples for distributed usage.
